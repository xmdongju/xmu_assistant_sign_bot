# 校园位置库

本位置库补充楼宇坐标与名称匹配，供现有课表解析和位置查询流程使用。数据在编译时内嵌，正常运行无需额外联网下载。

## 数据来源与覆盖范围

当前版本包含 **474 个地点**：翔安校区 150 个、思明校区 290 个、漳州校区 34 个。

- 460 条来自[厦大官方校园地图](https://map.xmu.edu.cn/)的公开楼宇接口 `/openmap/mapi/bd/v1/list`；校区编号分别为 377508、377507、377509。
- 上游原有 35 条地点记录完整保留于 `legacy_locations`；其中 21 条作为官方地点的兼容别名，另外 14 条保留为独立地点。
- 抓取时间、来源地址及逐条地图编号保存在 `app_data/locations.json`；用于生成的精简公开输入位于 `scripts/location-sources`。

坐标保留来源的原始经纬度数值，格式标记为 `xmu-map-native`。未推断或转换 GPS、GCJ-02 等坐标系。这些坐标为楼宇参考点，没有逐间教室实测或实际课程点名成功率声明。

## 名称兼容与匹配

规范名称包含校区；同校区重名地点另带地图编号。查询支持原有短名称及“学武楼101”“航院大楼”“嘉庚5-101”等常用写法。

优先匹配最长的有效名称或别名，楼号按完整数字边界匹配，避免“芙蓉1”匹配“芙蓉10”。若同名地点仍无法唯一确定，则返回无匹配结果；“图书馆”等跨校区名称需要提供校区。`LocationService::new`、`get`、`find` 与原有迭代接口继续可用。

原有位置缓存仍由原流程维护，固定位置库不会替代按活动存储的缓存。三点计算改为按原有三个参考地点的名称取点，避免位置数组扩展或排序改变计算基准。

## 外部配置

默认加载内置位置库。可通过 `XMU_LOCATION_FILE` 指定同结构 JSON，例如：

```powershell
$env:XMU_LOCATION_FILE = 'C:\bot\locations.json'
```

文件在进程首次加载位置库时读取，修改后重启生效。外部文件缺失、不可读、格式错误或坐标验证失败时，记录不含文件内容的警告并回退到内置副本。

格式要求为 `schema_version: 1`、`coordinate_system: "xmu-map-native"`；地点数量、文件体积、名称、别名、重复规范名称和本地区域坐标范围均有校验。外部列表将完整替代内置列表；若需保留原有三点计算能力，应保留“学武”“西部片区2号”“一期田径场”的可解析名称。

## 离线生成与验证

```sh
node scripts/build-location-catalog.cjs --check
node scripts/build-location-catalog.cjs
cargo test --locked --manifest-path scripts/location-tests/Cargo.toml
```

生成器只读取保存的公开响应，固定抓取时间，可离线复现相同 JSON。测试夹具直接导入生产位置模块，因此不需要 OpenCV、QQ 登录或学校网络。测试覆盖旧地点名称兼容、三个校区、别名、重名消歧、完整楼号、非法数据、原构造接口、最近点查询和参考点可解析性。
